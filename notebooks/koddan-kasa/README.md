# Koddan Kasa notebooks

**EN.** The notebooks behind the getporti **Koddan Kasa** short videos (Turkish). Each one reproduces the numbers shown in its video, runs on a free Colab CPU runtime and fetches the robot models it needs from MuJoCo Menagerie itself. The text inside the notebooks is Turkish; the code is plain Python.
